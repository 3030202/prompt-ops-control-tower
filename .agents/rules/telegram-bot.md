# Telegram Bot & Telethon Integration Rules

## 1. Telegram Bot API
- **Форматирование сообщений**: Всегда экранировать HTML-символы (`html.escape`) в динамических строках (`<`, `>`, `&`), либо использовать чистый текст с `parse_mode="HTML"`.
- **Long-polling (`getUpdates`)**:
  - Управлять параметром `offset = update_id + 1` для подтверждения обработки обновлений.
  - Обрабатывать статус 409 Conflict с задержкой (backoff) на случай перезапуска сервиса.
  - При ошибках сети не прерывать бесконечный цикл, логировать `warning` и повторять через `asyncio.sleep(3)`.
- **Интерактивные кнопки и WebApp**:
  - Кнопка запуска WebApp должна передавать корректный URL: `{"text": "...", "web_app": {"url": cfg.telegram_webapp_url}}`.
  - При получении `callback_query` ВСЕГДА отвечать через `answerCallbackQuery` в течение 5 секунд во избежание зависания индикатора загрузки в клиенте Telegram.

## 2. Telethon Userbot Safety
- Сессии Telethon хранятся в каталоге `sessions/` (никогда не коммитить файлы `.session`).
- Мониторинг каналов выполняется только на чтение (`events.NewMessage`).
- Запрещено выполнять отправку сообщений от имени userbot без явного указания оператора.
